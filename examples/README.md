# Examples

The example notebooks used to live in this directory as hand-maintained
copies. They have been removed: they had drifted out of step with the
library and could no longer run.

A worked example is now generated for you, ready to run, by:

```
fire-impacts new ./my-project
```

See the main [README](../README.md) for how to create and configure a
project, and [Configuring a study](../README.md#configuring-a-study) for
`study.toml`, the file that points the notebooks at your own data.
